# 오아시스휴양펜션 무료 홈페이지 1차 파일

## 구성
- `index.html`: 홈페이지 기본 페이지
- `styles.css`: PC/모바일 디자인
- `app.js`: 객실 표시 및 예약 신청 폼
- `config.js`: Apps Script 웹 앱 주소 설정
- `gas/Code.gs`: Google Apps Script 예약 접수 기본 코드

## 1. 먼저 확인할 점
이 파일은 **초기 제작본**입니다. 실제 운영 전에는 객실 사진, 정확한 주소/전화번호, 객실별 정원, 요금표를 실제 정보로 바꿔야 합니다. 현재 이미지 영역은 사진을 넣을 자리입니다.

## 2. GitHub Pages 배포
1. GitHub 계정 로그인 후 새 Public repository를 만듭니다. 예: `oasis-pension`
2. 이 폴더 안의 파일과 `assets` 폴더, `gas` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Build and deployment에서 `Deploy from a branch` 선택
4. Branch는 `main`, folder는 `/ (root)` 선택 후 Save
5. 잠시 후 `https://깃허브아이디.github.io/oasis-pension/` 주소로 접속합니다.

## 3. Google Apps Script 설정
1. 예약 데이터를 저장할 Google 스프레드시트를 엽니다.
2. 확장 프로그램 → Apps Script를 엽니다.
3. `gas/Code.gs` 내용을 편집기에 붙여넣습니다.
4. `setupSheets` 함수를 선택해 한 번 실행하고 권한을 승인합니다.
5. 배포 → 새 배포 → 유형 '웹 앱'
6. 실행 사용자: 나 / 액세스 권한: 모든 사용자로 배포합니다.
7. 생성된 `/exec` 주소를 복사합니다.
8. `config.js`의 `gasWebAppUrl`에 주소를 입력하고 GitHub에 다시 업로드합니다.

## 4. 중요: 실서비스 전 보완
- 이 1차본은 예약 신청 저장까지의 시작 버전입니다. 고객 브라우저에서 Apps Script 웹 앱으로 직접 POST하는 방식은 배포/브라우저 환경에 따라 CORS 또는 리다이렉트 제한이 발생할 수 있습니다. 실제 공개 전 반드시 휴대전화와 PC에서 접수 테스트를 해야 합니다.
- 승인/거절은 현재 Apps Script 편집기에서 함수 실행하는 기본형입니다. 다음 단계에서 관리자 전용 화면과 인증을 추가해야 합니다.
- 예약 가능 날짜 조회 API, 객실별 요금 계산, 자동 문자/이메일, 예약 대기 만료, Calendar 동기화는 아직 구현하지 않았습니다.
- 실제 고객 개인정보를 받기 전 개인정보 처리방침, 보유기간, 파기 절차를 정하고 필요한 동의를 받으세요.
- 웹 앱을 '모든 사용자'로 배포하면 공개 엔드포인트가 됩니다. 스팸 방지, 입력 검증, 관리자 인증 및 호출 제한을 보완한 후 운영하세요.
- GitHub Pages 저장소는 Public이어야 무료로 배포할 수 있습니다. 고객 개인정보나 비밀키를 저장소에 절대 올리지 마세요.
